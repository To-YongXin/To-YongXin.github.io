# 第六章媒体文件

把本章用到的文件放在这个目录，并在 `../index.html` 里对应修改 `src`。

| 文件（示例名） | 用途 |
|----------------|------|
| `magic.mp3` | 背景音乐（已配置） |
| `cover.jpg` | 第一页封面/氛围图 |
| `photo-01.jpg` ~ `photo-03.jpg` | 游玩照片 |
| `video-01.mp4` | 短视频（可多加 `video-02.mp4` 等） |

文件名可随意，改 HTML 里的路径即可。图片建议宽度适中（如 1080px 内），视频尽量压缩以加快加载。
